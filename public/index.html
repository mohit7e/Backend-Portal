    Auth

    POST /api/auth/register — No auth

    Register a new user. Body: { "username": "string", "password": "string" }. Username min 2 chars, password min 6. Returns { user: { id, username }, token }.

    POST /api/auth/login — No auth

    Log in. Body: { "username": "string", "password": "string" }. Returns { user: { id, username }, token }. Use Authorization: Bearer <token> for protected routes.

    GET /api/auth/me — Bearer token required

    Current user. Returns { id, username, role, created_at }.

    Response

    GET /api/projects/:id — No auth

    Get one project by id.

    POST /api/projects — Bearer token (developer or admin)

    Create project. multipart/form-data: title, developer_name, description, timeline, link, tech_stack, status, featured (0|1), tags (JSON array), images (files). Sets created_by from token.

    PUT /api/projects/:id — Bearer token (creator or admin)

    Update project. JSON or multipart. Multipart: same fields as POST + keep_images (JSON array of URLs to keep).

    DELETE /api/projects/:id — Bearer token (creator or admin)

    Delete project. Returns 204 No Content.

    Users (admin only)

    GET /api/users — Bearer token (admin)

    List all users. Returns array of { id, username, role, created_at }. Admin only.

    PUT /api/users/:id/role — Bearer token (admin)

    Set user role. Body: { "role": "viewer" | "developer" | "admin" }. Returns updated user. Admin only.

    Static

    GET /uploads/:filename — No auth

    Project images. Filenames come from project images array.
